## M0：可构建工程与真机验证

初始化 app + engine、Gradle Wrapper、版本目录、清单、主题、导航与权限入口。锁定实际 SDK/JDK/Gradle 组合，配置本机 SDK 路径时使用 local.properties 并忽略提交。

在用户手机验证事件：应用内页面跳转、应用切换、桌面、通知面板、锁屏、息屏、分屏、画中画、重启、后台限制。只记录必要事件字段，诊断导出由用户手动执行。形成设备能力表后落实状态机容差。

验收：工程能构建并安装；权限往返正常；历史读取与手机实际操作可以对应；项目构建、安装命令和设备信息写入本文件。

## M1：可信记录与日统计

实现 Room、原始事件、状态机、设备区间、覆盖标记、前台补采和后台补采；今日/历史日期的小时分布、应用构成、推算标记与可展开的原始会话。

验收：回看一天经过；重启应用与重复采集结果稳定；跨日、息屏及记录缺失有明确展示。

## M2：可复盘的个人版本

实现时段选择、应用详情、排行、用途标注和备注、JSON 备份恢复、CSV 导出、清空、隐私排除与保存策略。完成 P0。

验收：选中课程或晚间区间，核对用时并标注；数据库、界面与导出一致；恢复到空测试库后记录和标注一致。

## M3：长期回顾

周趋势、每日事实摘要、用途分布、线下活动补记、可选复盘提醒。先积累一周使用反馈，再决定课表导入与限额提醒。

## 关键统计验收样例

| 输入场景 | 预期行为 |
| --- | --- |
| 微信 10:00–10:10，浏览器 10:10–10:15 | 各 10 / 5 分钟；区间边界无重计 |
| 微信内部 Activity A 跳 B，旧 A 延迟暂停 | 应用连续会话保持；延迟事件只影响匹配 Activity |
| 23:45–次日00:30 持续使用 | 原会话 45 分钟，日贡献 15 / 30，开始次数 1 / 0 |
| 使用三小时且事件完整 | 保留三小时 |
| 应用使用中息屏 | 在息屏处结束设备使用与对应有效应用计时 |
| 第一次观察为 KEYGUARD_HIDDEN | 建立状态；后续完整锁屏到解锁转换再计数 |
| 浏览器持续后台放音乐 | 仅按前台使用口径计入，后台播放留在后续能力范围 |
| 5 分钟区间内两个应用全程并发 | 每应用可各 5 分钟，设备并集 5 分钟；并发标记清楚 |
| 一串 3 秒会话折叠 | 展示折叠，时间与次数保持 |
| 应用被隐藏后撤销隐藏 | 历史可恢复显示 |
| 隐私排除应用切入 | 前一应用按边界结束，保留匿名时段 |
| 数据采集中途失败 | 水位与数据一起回滚，重试后结果一致 |
| 相同窗口重复同步三次 | 事件重数、会话、摘要均稳定 |
| 同毫秒出现多个同类事件 | 保留必要重数与源顺序，避免误去重 |
| 用户标注后会话尾部重建 | 标注时间范围与内容保持 |
| 时段用途标注重叠 | 提示冲突，确认后切分，分类时长无重计 |
| 时区变化与夏令时边界 | epoch 会话保持，按时区重建日贡献 |
| 没有历史事件的查询返回空 | 显示来源覆盖状态，避免把整天填为息屏 |
| 清空并重新采集 | 从新起点采集，清理前的记录保持删除状态 |
| 备份格式损坏 | 恢复失败并保留当前库 |

## 本机环境与命令

- JDK 21，Gradle Wrapper 8.13，AGP 8.13.2，Kotlin 2.2.21，compile/target SDK 36。
- SDK：`D:/AndroidDev/Sdk`；AVD：`Keye_Phone_API_36`，Android 16 / API 36。
- 构建与静态检查：`./gradlew.bat :app:assembleDebug :app:lintDebug :engine:test`。
- 构建测试包：`./gradlew.bat :app:assembleDebugAndroidTest`；可用 `:app:connectedDebugAndroidTest` 或 ADB 安装两包并运行 `io.github.goooseby.tickmark.test/androidx.test.runner.AndroidJUnitRunner`。
- 安装：`D:/AndroidDev/Sdk/platform-tools/adb.exe install -r app/build/outputs/apk/debug/app-debug.apk`。
- 启动：`adb shell am start -n io.github.goooseby.tickmark/.app.MainActivity`。
- 本机直连 Maven Central TLS 握手失败，依赖仓库加入 Aliyun Central 镜像；Google 依赖仍从 Google 仓库解析。
