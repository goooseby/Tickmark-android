这一版着重整理设置、改善复盘，并修复启动后部分使用记录被错误标为未知的问题。

- 设置按任务分组，应用列表移入可搜索、筛选的“应用管理”。
- 新增每日与单应用目标、日/周用途统计、每日复盘和浅色/深色外观设置。
- 报表中的长段口径说明收进信息入口，采集原因与刷新操作放在“采集状态”。
- 修复亮屏与启动事件顺序处理，避免旧应用跨重启空档继续计时；同步时采样当前状态帮助接续。
- 支持 GitHub 更新检测、下载、安装包校验与系统安装，自动检查默认关闭。

使用记录、目标和复盘保存在本机，不上传。网络仅用于检查和下载更新。

这是开发中的个人版本。系统已清理的历史事件无法补回；厂商后台、分屏和安全锁屏仍需更多真机验证。调试包与正式签名包不能直接互相覆盖，首次从调试包迁移前请先导出 JSON 备份。
