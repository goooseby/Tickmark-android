# 桌面组件与未使用时段

2026-11-08，设计与实现基线。

## 统一数据投影

页面和组件共用 engine 的 DeviceReport 投影。使用、息屏、锁屏与未知沿相同毫秒边界裁剪；息屏和锁屏可合并为连续的“未使用时段”，但保留各自时长。相邻未知、缺失、重启或使用记录必须断开，不把没有应用事件视为未使用，也不自动命名为学习、睡眠或专注。

未使用表示系统有息屏或锁屏依据，不承诺用户完全没看锁屏。列表保留息屏/锁屏标签，详情提供口径。跨日只计当天交集，保留完整区间的开始时间，避免跨午夜时把一段拆成两次行为。进行中的记录只显示截至最后采集的时长，不从过期快照持续累加。

Room 事务读取统一 Records 快照，页面 Flow 与组件发布使用同一入口。每份不可变快照只规范化一次设备区间；日、周、用途、详情与组件均读取该区间，重叠冲突转为空档。设备投影与 UI/Glance 独立，组件只把投影转成布局，不复制统计规则。

## 页面

今日增加紧凑的“未使用手机”摘要与时段入口。详情展示累计、最长、全天分布和有意义的连续区间；默认至少5分钟，可查看全部。筛选只改变展示，不改变总量。点时段可进入该区间并补用途/备注，不把频繁应用切换重新作为主体列表。

## 组件

- 今日用时：主要数字、目标进度（设置后才出现）、小时分布和更新时间；较大尺寸可展示今天的小行动。
- 未使用时段：最长一段、对应起止、全天分布，较大尺寸增加累计及最近一段。
- 原生 Jetpack Glance，遵循桌面主题、系统圆角、文字缩放和可调尺寸。浅蓝/鼠尾草绿两组协调配色，数字与图形层级清楚，不加口号。
- 至少支持2×2与4×2，可继续放大。每个图形配数值/读屏描述；不以缩小触控目标塞满布局。
- 大字体下小组件移除图标及次要图形，保留完整标题；宽组件改为双指标，保留主要数据与更新时间。字体配置通过协调器发布到 Glance 状态，避免复用中的组件会话沿用旧布局。
- 点击主体进入相应页面，刷新为独立操作；设置可调用系统固定组件确认界面。

## 更新与状态

组件显示截至最后采集的结果。数据库提交后由统一协调器安排重绘；手动刷新和存在组件时的可延迟周期任务补采。无组件时不额外运行组件采集任务。系统日期/时区变化和组件尺寸变化触发重绘。授权缺失、采集暂停、暂无记录和旧快照都有简短可操作状态，不展示虚假实时倒计时。

组件缓存只有必要统计和用户主动写下的小行动，不包含完整应用列表与轨迹。组件内容在桌面可见，由用户主动添加。

## 验证

已验证连续息屏/锁屏、间隙、未知、重叠冲突、跨日、DST及随机区间分割不变量。组件/日统计/小时桶总量一致；另测半小时夏令时变化、事务快照、恢复冲突、入口日期及筛选/标注/返回流程。实际固定到 API36 Pixel Launcher，检查2×2、4×2、浅/深色与360dp大字体。完整检查结果见 [验证记录](validation/README.md)。真机厂商后台尚未验证。

可选视觉测试需先固定组件到 QA 模拟器桌面的下一页，再以 `-e widgetVisual true -e class io.github.goooseby.tickmark.WidgetReportTest#renderPinnedWidgetsForVisualInspection` 运行。该测试只替换组件缓存并保存截图，结束恢复真实聚合；常规全量测试会跳过它，避免自动测试改动桌面内容。正式数据库不注入样例。
